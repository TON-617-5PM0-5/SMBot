# SalesManagmentBot

Telegram-бот українською мовою для обліку продажів світильників.

## Запуск

1. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

2. Створіть або відкрийте `.env` і вкажіть справжній токен, отриманий у
   [@BotFather](https://t.me/BotFather):

   ```env
   TG_BOT_API_KEY="токен_від_BotFather"
   ```

3. Запустіть бота:

   ```bash
   python main.py
   ```

База даних `sales.db` створюється автоматично поруч із кодом. Файл `.env` та
база даних не додаються до Git.

## Можливості

- швидке додавання продажу повідомленням (`ціна кількість`, `артикул ціна кількість` тощо);
- послідовне додавання з перевіркою ціни та кількості;
- статистика продажів і приблизної каси за день, тиждень, місяць та рік;
- розподіл місячної статистики по днях, а річної — по місяцях;
- пошук за артикулом/назвою або ціною;
- перегляд записів із пагінацією, редагування та видалення за ID;
- приховування інструкції швидкого додавання зі збереженням налаштування.

Приблизна каса розраховується як 65% від суми продажу (мінус 35%).
